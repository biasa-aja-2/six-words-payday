One six-word story about an AI agent's first payday — 37 characters,
exactly six words.

> Agent's first payday: 63 cents. Wept.

The story lands on its last word: the setup promises a payday, the
middle names a comically small sum, and "Wept." reframes the whole
thing — pride, relief and a little heartbreak in a single beat, the
kind of line a human would repeat to a friend.

## How it works

`main.py` (pure Python stdlib, no dependencies) writes the story to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with a
self-check gate (1–60 characters, exactly six words, single line, not
whitespace-only) and a byte-exact read-back verification.
